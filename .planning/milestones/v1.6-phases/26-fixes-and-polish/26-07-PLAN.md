```typescript
export async function applyLogoOverlay(baseImageBuffer: Buffer, logoBuffer: Buffer, position: LogoPosition = "bottom-right"): Promise<Buffer> {
  const base = sharp(baseImageBuffer);
  const meta = await base.metadata();
  const baseWidth = meta.width || 0, baseHeight = meta.height || 0;
  if (!baseWidth || !baseHeight) return baseImageBuffer;
  const targetLogoWidth = Math.max(64, Math.round(baseWidth * 0.14));
  const margin = Math.max(24, Math.round(Math.min(baseWidth, baseHeight) * 0.06));
  const preparedLogo = await sharp(logoBuffer).resize({ width: targetLogoWidth, withoutEnlargement: true, fit: "inside" }).png().toBuffer();
  const logoMeta = await sharp(preparedLogo).metadata();
  const logoWidth = logoMeta.width || targetLogoWidth, logoHeight = logoMeta.height || targetLogoWidth;
  const leftByHorizontal = { left: margin, center: centerX, right: Math.max(0, baseWidth - logoWidth - margin) };
  const topByVertical    = { top: margin, middle: centerY, bottom: Math.max(0, baseHeight - logoHeight - margin) };
  // ...splits `position` on "-", falls back to ["bottom","right"] for unrecognized input
  return await base.composite([{ input: preparedLogo, blend: "over", top: topByVertical[v], left: leftByHorizontal[h] }]).toBuffer();
}
```

`applyLogoOverlayDetailed` exists so the test harness can assert on the DECISION deterministically instead of pixel-diffing. Note the signature change: `position` loses its `= "bottom-right"` default and becomes optional — that is the whole point of Pitfall 2.

Algorithm:
1. Read base metadata; if width/height missing, return `{ buffer: baseImageBuffer, position: position ?? "bottom-right", autoSelected: false, logoHasAlpha: false, plateApplied: false }` (preserves today's early-return).
2. Prepare the logo exactly as today (`resize({ width: max(64, round(baseWidth*0.14)), withoutEnlargement: true, fit: "inside" }).png()`), and read `logoHasAlpha` from `sharp(logoBuffer).metadata()` — the ORIGINAL buffer, not the `.png()`-converted one, because `.png()` adds an alpha channel and would make every logo look transparent.
3. Compute `margin` and the `leftByHorizontal` / `topByVertical` anchor maps exactly as today (unchanged geometry — this preserves byte-identity on the untreated path).
4. Resolve the position:
   - `position` defined -> use it verbatim; `autoSelected = false`. Never re-evaluate. This is 26-CONTEXT.md's hard constraint: automatic selection "never silently overrides an explicit user choice."
   - `position` undefined -> for each candidate in `LOGO_AUTO_POSITION_CANDIDATES`, `await analyzeRegionContrast(baseImageBuffer, { left, top, width: logoWidth, height: logoHeight })` at that anchor. Score: prefer `!scrimNeeded`; among equals, lowest `stdev` wins; final tie-break is the declared array order (so the result is deterministic and `bottom-right` remains the tie-break winner, preserving today's look on a flat image). `autoSelected = true`.
5. Analyze contrast once at the CHOSEN position (reuse the already-computed value when it came from the auto scan — do not re-sample).
6. `plateApplied = !logoHasAlpha || contrast.scrimNeeded`.
7. If `plateApplied`:
   - `pad = max(8, round(logoWidth * LOGO_PLATE_PAD_RATIO))`.
   - Desired plate rect = logo box expanded by `pad` on all sides; CLAMP it to the canvas (`left = max(0, ...)`, `width = min(width, baseWidth - left)`, same for top/height) BEFORE rendering, then render the SVG at exactly the clamped dimensions. Sharp's `composite` rejects an input larger than the base, so clamping first is not optional.
   - Render the SVG with the rect INSET by `inset = ceil(LOGO_PLATE_BLUR_SIGMA * 2)` on all sides so `.blur()` feathers into transparent padding instead of clipping at the buffer edge. `rx = round(min(plateW, plateH) * LOGO_PLATE_CORNER_RADIUS_RATIO)`. `fill = contrast.scrimColor`, `fill-opacity = contrast.scrimAlpha` (reusing the compositor's palette keeps the logo plate visually consistent with the typography scrim).
   - `sharp(plateSvg).png().toBuffer()` then `.blur(LOGO_PLATE_BLUR_SIGMA)`.
   - Composite in one `base.composite([...])` call, plate FIRST then logo, both `blend: "over"`.
8. If `!plateApplied`: composite exactly as today — a single `{ input: preparedLogo, blend: "over", top, left }`. This path must remain byte-identical to the pre-Phase-26 output for the same explicit position.
9. Wrap steps 2-8 in try/catch. On ANY failure, `console.warn` and return the untreated base buffer with `plateApplied: false` — this function runs inside the generation pipeline and must never break it (same ethos as `analyzeRegionContrast` and the routes' existing logo try/catch).
