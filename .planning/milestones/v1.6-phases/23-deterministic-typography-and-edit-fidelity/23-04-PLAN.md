    Constants (exact names and values):
    - `export const LUMINANCE_TEXT_SWITCH = 140;` — above this the region is "light", so use dark text
    - `export const MIN_LUMINANCE_DELTA = 90;` — required `|L_text - L_bg|` on the 0-255 scale
    - `export const BUSY_STDEV_THRESHOLD = 55;` — high variance = busy region, scrim regardless of mean
    - `export const MID_BAND_LOW = 90;` and `export const MID_BAND_HIGH = 170;`
    - `export const TEXT_COLOR_LIGHT = "#FFFFFF";` and `export const TEXT_COLOR_DARK = "#111111";`
    - `export const SCRIM_ALPHA_DARK = 0.45;` (black scrim behind white text) and `export const SCRIM_ALPHA_LIGHT = 0.55;` (white scrim behind dark text)

    `export interface RegionContrast { luminance: number; stdev: number; textColor: string; scrimNeeded: boolean; scrimColor: string; scrimAlpha: number; }`

    `export async function analyzeRegionContrast(baseBuffer: Buffer, region: { left: number; top: number; width: number; height: number }): Promise<RegionContrast>` — deterministic algorithm, documented inline as "WCAG-inspired, not WCAG-conformant" per 23-CONTEXT.md:
    1. Clamp `region` to the image's real bounds first (`sharp(baseBuffer).metadata()`); sharp throws on an out-of-bounds `.extract()`.
    2. `const { channels } = await sharp(baseBuffer).extract(clamped).stats();`
    3. `luminance = 0.299*channels[0].mean + 0.587*channels[1].mean + 0.114*channels[2].mean`. If fewer than 3 channels are present, use `channels[0].mean` for all three terms.
    4. `stdev = (channels[0].stdev + channels[1].stdev + channels[2].stdev) / 3` (same fewer-than-3 guard).
    5. `textColor = luminance > LUMINANCE_TEXT_SWITCH ? TEXT_COLOR_DARK : TEXT_COLOR_LIGHT`.
    6. `textLuminance = textColor === TEXT_COLOR_LIGHT ? 255 : 17`.
    7. `scrimNeeded = Math.abs(textLuminance - luminance) < MIN_LUMINANCE_DELTA || stdev > BUSY_STDEV_THRESHOLD || (luminance >= MID_BAND_LOW && luminance <= MID_BAND_HIGH)`.
       Document the third clause: "a mid-luminance background defeats BOTH white and dark text at typical photographic variance, so the mid band always gets a scrim." This clause is what makes the flat rgb(128,128,128) fixture scrim (its raw delta of 127 would otherwise pass) while the rgb(12,12,12) fixture correctly does not.
    8. `scrimColor = textColor === TEXT_COLOR_LIGHT ? "#000000" : "#FFFFFF"`; `scrimAlpha = textColor === TEXT_COLOR_LIGHT ? SCRIM_ALPHA_DARK : SCRIM_ALPHA_LIGHT`.
    9. Wrap 1-8 in try/catch. On ANY error return the fail-toward-legibility default `{ luminance: 128, stdev: 0, textColor: TEXT_COLOR_LIGHT, scrimNeeded: true, scrimColor: "#000000", scrimAlpha: SCRIM_ALPHA_DARK }` and `console.warn`. Never throw.

    Type-size constants (fractions of `base = Math.min(width, height)`; Claude's-discretion per 23-CONTEXT.md — document as such):

    - `export const AUTOSHRINK_STEP = 0.94;` and `export const MIN_SIZE_RATIO = 0.030;`
    - `export const BLOCK_GAP_RATIO = 0.35;` (gap between blocks, as a fraction of that block's line height)

    `function wrapTextToWidth(ctx, text: string, maxWidth: number): string[]` — greedy word-wrap using `ctx.measureText(candidate).width` (Pitfall 4: Canvas 2D has no built-in wrapping). A single word longer than `maxWidth` must be emitted on its own line rather than looping forever.

    `function layoutBlocks(ctx, blocks: TextBlock[], region, base: number)` — for each block compute `size = Math.round(ROLE_SIZE_RATIO[role] * base)`, set `ctx.font = \`${size}px ${ROLE_FONT_ALIAS[role]}\`` (NEVER a `bold `/`700 ` weight keyword — Pitfall 5), wrap to `region.width`, and sum `lines.length * Math.round(size * LINE_HEIGHT_RATIO)` plus inter-block gaps. If the total exceeds `region.height`, multiply every size by `AUTOSHRINK_STEP` and recompute, looping until it fits or any size would drop below `Math.round(MIN_SIZE_RATIO * base)` (then accept the minimum and clip). Return the per-block layout (`role`, `alias`, `size_px`, `line_height_px`, `lines: string[]`) plus the total block height.

    `export async function compositeTypography(params: { baseImageBuffer: Buffer; textBlocks: TextBlock[]; layoutArchetypeId: LayoutArchetypeId; aspectRatio?: string }): Promise<{ buffer: Buffer; meta: TypographyMeta }>`:
    1. `registerBundledFonts()`.
    2. Read real dimensions from `sharp(params.baseImageBuffer).metadata()` — do NOT trust a caller-supplied width/height.
    3. If `params.textBlocks.length === 0`, return `{ buffer: params.baseImageBuffer, meta }` with `meta.text_blocks: []`, `meta.fonts: []`, `meta.scrim: null` — a no-text post must be a cheap pass-through, not a re-encode of the same pixels through canvas.
    4. `const region = computeArchetypeRegion(...)`, `const safeZone = computeSafeZone(...)`.
    5. `const contrast = await analyzeRegionContrast(params.baseImageBuffer, region)`.
    6. `const canvas = createCanvas(width, height); const ctx = canvas.getContext("2d"); ctx.drawImage(await loadImage(params.baseImageBuffer), 0, 0, width, height);`
    7. Lay out the blocks (`layoutBlocks`) to learn the real drawn text height.
    8. Scrim, if `contrast.scrimNeeded`, drawn BEFORE any text:
       - `bottom_band`: full-width rect from `y = region.top - Math.round(height * 0.03)` to the bottom edge.
       - `top_stack`: full-width rect from `y = 0` to `region.top + region.height + Math.round(height * 0.03)`.
       - `centered_hero`: a rect covering the laid-out text bounding box padded by 4% of `base` on all sides, clamped to the canvas.
       Draw with `ctx.globalAlpha = contrast.scrimAlpha; ctx.fillStyle = contrast.scrimColor; ctx.fillRect(...); ctx.globalAlpha = 1;`. Record the exact integer rect in `meta.scrim.region`.
    9. Text: `ctx.fillStyle = contrast.textColor`. `bottom_band` and `top_stack` are left-aligned at `region.left` with `ctx.textAlign = "left"`; `centered_hero` is centered at `region.left + region.width / 2` with `ctx.textAlign = "center"`. Vertical anchor: `bottom_band` bottom-anchored inside the region, `top_stack` top-anchored, `centered_hero` vertically centered. Set `ctx.textBaseline = "top"` and advance `y` by `line_height_px` per line, plus `Math.round(line_height_px * BLOCK_GAP_RATIO)` between blocks.
    10. `const buffer = await canvas.encode("png");` — PNG, lossless. The single lossy WebP pass happens later in `processImageWithThumbnail`, never here.
    11.     12. Wrap 2-11 in try/catch: on error `console.error("[typography] composite failed, returning base image:", err)` and return `{ buffer: params.baseImageBuffer, meta }` with `scrim: null` and `fonts: []`. A compositor failure must degrade to a text-free image, never break a generation.
