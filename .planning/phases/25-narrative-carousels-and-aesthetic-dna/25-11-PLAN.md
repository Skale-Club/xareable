Create `client/src/components/admin/post-creation/style-reference-boards-card.tsx`.

Header comment: Phase 25 (PLAN-07). Explains that unlike every sibling card, this one does NOT participate in the batched `catalog`/`setCatalog` save — `style_reference_photos` is a real relational table, so this card owns its own `useQuery`/`useMutation` pair with immediate persistence (25-RESEARCH.md "Critical architectural note").

```typescript
interface StyleReferenceBoardsCardProps {
  catalog: StyleCatalog;   // read-only: supplies the style/mood ids + labels to group by
}
export function StyleReferenceBoardsCard({ catalog }: StyleReferenceBoardsCardProps)
```
Note: NO `setCatalog` prop — it must be structurally impossible for this card to dirty the batched catalog state.

Behavior:
- `useQuery<StyleReferencePhotosResponse>({ queryKey: ["/api/admin/style-reference-photos"], queryFn: () => adminFetch("/api/admin/style-reference-photos") })` — one unfiltered fetch, grouped client-side.
- Group photos into `Map<"style" | "post_mood", Map<style_id, StyleReferencePhoto[]>>`, each list sorted by `position`.
- Render a `Card` (title `t("Style Reference Boards")`, description `t("Platform-curated reference images attached to generation when a style or mood is selected.")`) containing two `Accordion`s: one over `catalog.styles`, one over `catalog.post_moods`. Each `AccordionTrigger` shows the entry label plus a `Badge` with its image count.
- Each `AccordionContent`: a responsive image grid (`grid-cols-4`) of thumbnails, each with a hover `X` delete button, plus an "Add image" file input tile shown only while `photos.length < MAX_STYLE_REFERENCE_PHOTOS`.
- Upload flow (copy `sceneries-card.tsx`'s pattern): validate the file is an image and <= 5 MB; upload via the admin's own authenticated `supabase()` client to `user_assets` at `${user.id}/style-boards/${scope}-${styleId}-${Date.now()}.${ext}`; then POST `{ scope, style_id, photo_url }`; then `queryClient.invalidateQueries({ queryKey: ["/api/admin/style-reference-photos"] })`.
- Delete flow: `DELETE /api/admin/style-reference-photos/:id` (use the same `supabase().auth.getSession()` + `Authorization: Bearer` fetch idiom `post-creation-tab.tsx` uses for its PATCH), then invalidate.
- Toasts on success and failure through `useToast`, all strings through `t(...)`.
- While `isLoading`, render a skeleton/placeholder row rather than `null` (the card must never disappear).

Then add `export * from "./style-reference-boards-card";` to `client/src/components/admin/post-creation/index.ts`.
