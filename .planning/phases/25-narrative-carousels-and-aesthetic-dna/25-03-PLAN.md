```typescript
export const SLIDE_ROLES = ["hook", "content", "cta"] as const;
export type SlideRole = typeof SLIDE_ROLES[number];

export const MIN_COMPOSITION_NOTE_LENGTH = 15;
// Two composition_notes whose normalized token sets overlap at or above this
// Jaccard ratio count as "the same framing" for ROADMAP SC2's automated
// inter-slide composition-similarity check.
export const COMPOSITION_SIMILARITY_THRESHOLD = 0.8;

export interface CarouselWireSlide {
  slide_number: number;
  image_prompt: string;
  role: SlideRole;            // model emits it for schema symmetry; SERVER OVERWRITES IT
  composition_note: string;
  text_blocks: TextBlock[];
}
export interface CarouselWirePlan {
  shared_style: string;
  layout_archetype_id: LayoutArchetypeId;  // chosen ONCE for the whole carousel
  slides: CarouselWireSlide[];
  caption: string;
}
```

`assignSlideRoles<T extends { role?: string }>(slides: T[]): Array<T & { role: SlideRole }>`
- Returns a NEW array of NEW objects (`{ ...slide, role }`) — never mutates inputs.
- `i === 0` → `"hook"`; `i === slides.length - 1 && slides.length > 1` → `"cta"`; else `"content"`.
- A single-slide array yields `["hook"]` (hook wins over cta).
- Add a comment stating verbatim: the model's own `role` value is discarded here — 25-CONTEXT.md locks server-side deterministic assignment.

`normalizeCompositionNote(note: string): string[]`
- lowercase → replace `/[^\p{L}\p{N}\s]/gu` with `" "` → collapse whitespace → split on space → drop tokens shorter than 3 chars EXCEPT keep the raw normalized string available for the exact-equality path.

`findDuplicateCompositionNotes(slides: Array<{ slide_number: number; composition_note: string }>): Array<{ a: number; b: number; similarity: number }>`
- For every unordered pair: if both normalized strings are byte-equal → similarity 1. Otherwise compute Jaccard over the token sets (`|A∩B| / |A∪B|`; both empty → 1).
- Emit a pair whenever `similarity >= COMPOSITION_SIMILARITY_THRESHOLD`.
- `a`/`b` are `slide_number` values.

`compositionNotesAreVaried(slides): boolean` → `findDuplicateCompositionNotes(slides).length === 0`.
